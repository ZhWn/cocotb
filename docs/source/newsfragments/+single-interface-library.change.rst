Each simulator interface library now contains the whole cocotb GPI and IPC server stack statically and carries all GPI interfaces (VPI/VHPI/FLI) that the simulator's flows can use, so exactly one library file is loaded per simulation run; the secondary interfaces needed for mixed-language simulation are now activated by name with, for example, ``GPI_EXTRA=vhpi`` instead of by ``path/to/library.so:entry_point`` pairs, which are no longer supported.
