Standalone shared-library builds can embed the cocotb Python packages into the simulator-side library with the new ``COCOTB_IPC_EMBED_ZIP`` CMake option, letting the testbench process import cocotb even from a Python environment where cocotb is not installed; the embedded zip is unpacked to a content-verified cache file in the system temporary directory and injected after the user's ``PYTHONPATH``, so a locally provided cocotb always takes precedence (see the ``COCOTB_IPC_EMBED`` environment variable).
